# E-commerce Website

A modern e-commerce website built with React.js. The application provides a user-friendly shopping experience with product browsing, search, cart management, authentication and an admin dashboard.

## Features

### Customer

* Home page
* Product listing
* Product details
* Categories
* Product search
* Product filtering
* Product sorting
* Pagination
* User registration and login
* Shopping cart
* Checkout
* Address management
* Order management
* Wishlist

### Admin

* Admin login
* Dashboard
* Product management
* Category management
* Order management
* User management
* Admin settings

## Tech Stack

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Go to the project folder:

```bash
cd ecommerce-client
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run locally using the URL provided by Vite.

## Backend

This frontend communicates with a REST API built using:

* Node.js
* Express.js
* PostgreSQL
* JWT authentication
